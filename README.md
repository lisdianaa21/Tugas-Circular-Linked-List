# Tugas Circular Linked List

**Mata Kuliah:** Struktur Data

## Deskripsi
Program ini dibuat untuk mengelola data mahasiswa menggunakan struktur data Circular Singly Linked List.

## Data Mahasiswa
- Nama
- NIM
- Gender
- Nilai

## Fitur Program
1. Insert Data: Menambahkan data mahasiswa.
2. Hapus Data: Menghapus data berdasarkan NIM.
3. Cetak Data: Menampilkan seluruh data mahasiswa.
4. Exit: Keluar dari program.

## Ketentuan
Data mahasiswa diurutkan secara menaik berdasarkan NIM.

## Bahasa Pemrograman
C++
